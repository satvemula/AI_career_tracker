# AI Career Tracker  

Track and visualize AI learning progress, milestones, and daily goals using Streamlit and Plotly.  

## Overview  
The AI Career Tracker is a productivity and accountability tool for learners pursuing AI skills. It allows users to set learning goals, log daily/weekly progress, and visualize growth through interactive dashboards.  

## Features  
- Track AI learning hours, milestones, and goals  
- Visualize progress with interactive Plotly graphs  
- Input and store historical learning data  
- Simple, browser-based interface via Streamlit  

## Tech Stack  
- **Python**  
- **Streamlit**  
- **Plotly**  
- **Pandas**
